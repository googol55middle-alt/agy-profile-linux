agy-profile-linux

Save multiple Antigravity CLI (agy) account profiles, switch the live account, or run a profile in an isolated home. Optional policies help external tools coordinate account changes after quota or authentication failures.

This project is not affiliated with Google, Antigravity, or the upstream maintainers.

What it does

  • Manage multiple agy accounts from one runtime.
  • Store account profiles with restrictive permissions and atomic updates.
  • Optionally switch away from a low-quota or failed account in automatic mode.
  • Coordinate runtime failover to avoid double account switching.
  • Expose machine-readable APIs for bots and schedulers.
  • Support manual and automatic switching policies.

Install

git clone https://github.com/googol55middle-alt/agy-profile-linux.git
cd agy-profile-linux
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .

Security

OAuth credentials are stored as owner-readable local files, not encrypted secrets. Protect the host, backups, snapshots, and any custom manager root. Review SECURITY.md before using real accounts.

Core features

Quota-aware switching

In automatic mode, use cached short-window thresholds and refresh-failure counters to choose when to leave an account. Cached values are advisory.

Ranked account pool

Rank eligible standby accounts using saved health and short-window quota metadata instead of rotating by name.

Automation API

Control switch mode, switch policy, usage refresh, and failover through CLI commands or a Python API.

Runtime failover control

Coordinate one account change after a failure so an external caller can decide whether to retry.

Terminal dashboard

Inspect active, standby, cooldown, usage, and switch runtime state from a focused TUI built for operator workflows.

External integrations

Call the CLI or Python API from bots, schedulers, or other local automation that needs coordinated account switching.

Python API example

from pathlib import Path
from agy_profile_linux import build_paths, get_switch_policy, update_switch_policy

paths = build_paths(Path.home() / ".agy-profile-linux")
policy = get_switch_policy(paths)

update_switch_policy(
    paths,
    short_usage_threshold_percent=12.5,
    refresh_failure_threshold=3,
    candidate_strategy="highest-short",
)

Use cases

agy-profile-linux is useful on Linux for Telegram bots, automation workers, cron or systemd timers, multi-account Antigravity CLI auth setups, runtime account rotation, account login storage, and failover-aware local tooling.
